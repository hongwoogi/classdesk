내 바탕화면에 작은 교실을.

  1. 장면을 골라요

    해변, 초원, 칠판, 운동장, 체육관, 교실 중 하나를 선택하세요. 기존 풍경 2종에 학교 테마 4종을 더했어요.

  2. 자료를 모아봐요

    미리보기 아이콘을 끌거나, 선택 후 방향키로 옮기면 경계가 자동으로 바뀌어요. Shift와 방향키를 함께 누르면 크게 이동해요.

  3. 우리 반의 느낌으로

    묶기 거리, 여백, 선 두께와 모둠 이름을 조절해 보세요. 설정은 이 기기에 저장돼요.

Windows 바탕화면에 적용

ClassDesk-0.1.0-win-x64-Setup.exe를 실행해 설치한 뒤, 시작 메뉴에서 교실데스크를 여세요. Windows 10·11과 .NET Framework 4.8, Edge WebView2가 필요해요. 설치 프로그램이 필수 구성 요소를 확인해요. 종료하면 원래 배경으로 돌아가요.

설치 없이 쓰려면 포터블 ZIP의 압축을 모두 풀고 host\bin\ClassDesk.exe를 실행하세요.

브라우저는 예시 아이콘으로만 동작해요. Windows 버전은 실제 아이콘의 위치만 읽고 파일을 이동하거나 이름을 수집하지 않아요. 배경 이미지에는 파일명이 포함되지 않아요.

이 프로그램은 Deskland의 공개 소스를 바탕으로 만든 독립 파생 버전이며, 원작자의 공식 제품이 아니에요. 소스는 GPL-3.0으로 제공해요.
