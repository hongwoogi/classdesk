# 교실데스크 화면 기준

## 방향

학교에서 익숙한 재료를 정확하게 그리는 도구다. 배경은 칠판·흙바닥·나무 마루·교실 평면도를 따르고, 조절 화면은 따뜻하고 절제된 흰색 작업 공간으로 만든다. 교육용 캐릭터, 무의미한 장식, 추상적인 색상 변화로 테마를 대신하지 않는다.

참고한 원칙: interface-design의 일관된 간격·명시적 토큰·실제 작업 중심 화면, Impeccable의 기능적 위계·실제 테마 차별화·상태와 접근성 검수.

## 토큰

- 기본 4px 간격, 콘텐츠 간격 8·12·16·24·32px.
- 바탕 `#f5f5f0`, 패널 `#ffffff`, 본문 `#263b34`, 보조 `#70796e`, 경계 `#e3e6df`.
- 주요 동작 `#2d6754`, 눌림 `#204f40`, 선택 바탕 `#edf2eb`.
- 테마 질감은 절차적으로 생성하고 외부 이미지에 의존하지 않는다.
- Pretendard Variable, Material Symbols Rounded를 로컬 파일로 제공한다. 아이콘과 본문에 이모지를 쓰지 않는다.

## 화면 구성

- 상단: 자체 로고·제품 이름·브라우저 또는 Windows 연결 상태·사용 안내.
- 왼쪽: 네 가지 장면. 선택 상태는 색상뿐 아니라 `aria-pressed`로도 나타낸다.
- 가운데: 실제 Canvas 미리보기·예시 아이콘 배치·이동 되돌리기·PNG 배경 저장.
- 오른쪽: 거리·여백·재료·이름 조절. 로컬 저장 결과를 실제 성공 여부에 따라 안내한다.
- 좁은 화면: 장면 선택을 네 칸 가로 줄로 올리고 미리보기 다음에 설정을 쌓는다. 페이지 전체 가로 넘침을 숨겨서 버그를 가리지 않는다.

## 상호작용

- 아이콘은 Canvas의 실제 좌표와 대응하는 DOM 버튼으로 드래그·키보드 이동한다.
- Windows에서는 미리보기 아이콘 이동 버튼을 비활성화하고 실제 바탕화면에서 이동하도록 안내한다.
- 배경 이미지는 파일명·파일 아이콘 없이 저장한다.
- 오류·저장 제한·없는 실행 환경은 그 상태를 그대로 표시한다.
- 그리기 효과는 짧게 실행한 뒤 멈춘다. 백그라운드에서 불필요한 연속 렌더링을 하지 않는다.
